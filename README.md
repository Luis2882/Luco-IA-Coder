# 🤖 Luco AI Coder

O **Luco AI Coder** é um assistente de inteligência artificial voltado para desenvolvimento e geração de código, combinando a alta velocidade de processamento da API da **Groq** com uma interface interativa e amigável construída em **Streamlit**.

---

## 🚀 Funcionalidades

* 💻 **Assistente de Código:** Ajuda na escrita, refatoração, explicação e depuração de código em diversas linguagens.
* ⚡ **Alta Performance:** Respostas ultra-rápidas utilizando os modelos de LLM via API da **Groq**.
* 💬 **Interface Interativa:** Chat simples e intuitivo desenvolvido em **Streamlit**.

---

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* **Streamlit** (para interface web)
* **Groq API** (Llama 3 / Mixtral)

---
